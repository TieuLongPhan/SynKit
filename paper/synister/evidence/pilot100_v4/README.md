# Blinded FlowER pilot evidence

This directory freezes the first 100 records processed by the schema-v4
Synister global-shell runner. The input dataset itself is not redistributed;
its SHA-256 identifier is recorded in `manifest.json`.

The run used one Python process and one numerical thread, a hard 6 GiB address
space limit, one second per shell, at most 10,000 selected mappings, and exact
ITS/template canonicalization bounded at 0.1 seconds per representative. Both
the reference-distance and globally minimal heavy-atom shells were queried.
Endpoint atom orders were independently blinded. A reference-free SLAP map was
permitted only as a feasible incumbent and branch-ordering seed.

`cases/` contains immutable gzip JSON records. These contain neither a raw
reference mapping nor reaction SMILES. Each record carries a payload digest
and the manifest digest. `summary.json` is generated by the campaign runner;
`derived_findings.json` is reproducibly generated by
`scripts/summarize_synister_evidence.py`. Timeouts and mapping limits are
incomplete records and are excluded from complete-shell denominators.
Reference-class counts in the derived summary use exact canonical ITS class
identity, not a finite digest or index-equality surrogate.
The same verified records also derive the candidate-complete application yield:
39 non-reference ITS classes across 16 closed minimal-shell cases and 54 across
18 closed reference-CD cases.

This is a deliberately small, resource-bounded pilot, not an estimate for all
10,000 FlowER reactions. The manuscript labels it accordingly.
