# Published Cayley Atom Tracker comparison

The separately downloaded implementation is https://github.com/Nojgaard/cat,
pinned to commit `aeafb3963e72eb0f2b8e873eb812a576a9ab1064`.
It accompanies Nøjgaard, Fontana, Hellmuth and Merkle (2021),
*Cayley Graphs of Semigroups Applied to Atom Tracking in Chemistry*,
Journal of Computational Biology 28(7), 701–715,
https://doi.org/10.1089/cmb.2020.0548.

Its original modules execute unmodified from `/tmp/mtg-cat`; no upstream
source is bundled or copied into this repository. The occurrence-network
view, protocol, certificate-to-map adapter and comparison report are original
research code here. The supplied formose example is executed through its
calculation, omitting only graphical-output calls.

The author-hosted primary paper is
https://fontana.hms.harvard.edu/sites/fontana.hms.harvard.edu/files/documents/Nojgaard-2021.pdf.
The protocol records its digest. This review package contains transformed
comparison evidence and citations, not the full paper or external source tree.
